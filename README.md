# Site-Psicologa

# 🧠 Site Institucional – Consultório de Psicologia  Projeto de um site moderno e responsivo desenvolvido para um consultório de psicologia, com foco em apresentação profissional, experiência do usuário e facilidade de contato.  ---  

## 🚀 Objetivo  Este projeto foi criado com o objetivo de fornecer uma presença online profissional para um consultório de psicologia, permitindo:  * Apresentação dos serviços * Explicação dos planos de atendimento * Contato rápido via WhatsApp * Experiência agradável e acolhedora ao usuário. 

---  
 
 ## 🛠️ Tecnologias Utilizadas  * **HTML5** → Estrutura do site * **CSS3** → Estilização moderna (cores nude e layout responsivo) * **JavaScript** → Interações (botão de agendamento via WhatsApp)  ---  ## 🎨 Layout e Design  O design foi pensado para transmitir:  * Acolhimento * Profissionalismo * Simplicidade * Leveza visual  Utilizando cores suaves (nude) e espaçamento bem distribuído.

 ---  
 
 ## 📱 Responsividade  O site é totalmente responsivo, adaptando-se para:  * 📱 Celulares * 💻 Computadores * 📟 Tablets  
 ---  

 ## 📌 Funcionalidades  * ✅ Navegação simples e intuitiva * ✅ Seção “Sobre o consultório” * ✅ Planos de atendimento com descrição * ✅ Botão de agendamento via WhatsApp * ✅ Número clicável para contato * ✅ Estrutura leve e rápida 
 
---  
 
 ## 🔗 Integração com WhatsApp  O botão de agendamento redireciona automaticamente para o WhatsApp com uma mensagem pré-definida:  ```js function agendar() {   const numero = "5511999999999";   const mensagem = encodeURIComponent("Olá, gostaria de agendar uma consulta.");   window.open(`https://wa.me/${numero}?text=${mensagem}`, '_blank'); } ```

## ✏️ Personalização  Você pode facilmente adaptar o projeto:  * Alterar textos diretamente no HTML * Substituir imagens (atualmente usando https://picsum.photos) * Modificar cores no `:root` do CSS * Alterar número do WhatsApp no JavaScript
