# 🧠 Site – Consultório de Psicologia

Site institucional moderno e responsivo desenvolvido para um consultório de psicologia, com foco em apresentação profissional e contato facilitado via WhatsApp.

---

## 🚀 Tecnologias

* HTML5
* CSS3
* JavaScript

---

## 📌 Funcionalidades

* Apresentação do consultório
* Planos de atendimento (sem exibição de preços)
* Botão de agendamento via WhatsApp
* Número clicável
* Layout responsivo

---

## 🌐 Como executar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador

---

## ✏️ Personalização

* Altere textos no HTML
* Modifique cores no CSS (`:root`)
* Troque imagens (atualmente aleatórias)
* Atualize o número do WhatsApp no JavaScript
